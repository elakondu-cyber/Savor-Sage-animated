# 🍷 Savor & Sage — Luxury Animated Restaurant Website Template

A modern, responsive, multi-page restaurant website template built with pure **HTML5 and CSS3**. Designed with fluid micro-interactions, cinematic scroll triggers, and smooth keyframe animations to deliver a high-end digital dining experience.

---

## ✨ Features

- **Cinematic Visual Effects:** Smooth keyframe entry animations, pulse-glowing CTA buttons, and subtle hero background zoom dynamics.
- **Micro-Interactions:** Card elevation and hover-scaling dish previews across the menu section.
- **3-Page Layout Structure:**
  - `index.html` — Hero section, chef's culinary story, and venue highlights.
  - `menu.html` — Interactive food & beverage grid with dynamic pricing tags.
  - `contact.html` — Sleek reservation booking form with active input glow states.
- **Clean File Separation:** All layout rules and CSS keyframes are isolated in `style.css` so page content remains easy to edit without breaking styles.
- **Zero Heavy Dependencies:** Lightweight code for maximum page load speeds.
- **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile displays.
